# StockHub - Test Technique

Système de gestion d'inventaire e-commerce multi-canal. Ce projet sert de base pour un test technique d'évaluation de développeurs.

## Structure

```
├── docs/
│   ├── architecture.md    # Diagrammes et description des composants
│   └── business_context.md # Contexte métier e-commerce
└── src/
    ├── inventory/         # Modèles et logique de stock
    ├── sync/              # Synchronisation marketplaces
    └── webhooks/          # Réception des notifications
```

## Visualiser les diagrammes

Le fichier `docs/architecture.md` contient des diagrammes Mermaid. Pour les visualiser :

- **GitHub** : Les diagrammes s'affichent automatiquement
- **VS Code** : Installer l'extension [Markdown Preview Mermaid Support](https://marketplace.visualstudio.com/items?itemName=bierner.markdown-mermaid)
- **En ligne** : Copier le code Mermaid sur [mermaid.live](https://mermaid.live)
